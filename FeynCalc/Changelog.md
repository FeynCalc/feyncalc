## New functionality
* Added new routines FCLoopToGLI, FCLoopFactorizingQ, FCLoopFactorizingSplit and FCLoopCreateFactorizingRules for dealing with factorizing loop integrals. (8a112918)
* Added new options Flatten and Remove to FCLoopFindSubtopologies. (d6709a47)
* Added more parallelization to FCLoopTensorReduce. (b0c3aeeb)
* Added FRH2, a special FRH for using Collect2 with IsolateNames in the parallel mode. (7d266d89)
* Added parallelization to DotSimplify. (80e855f3)
* Added new function FCLoopRewriteIncompleteTopologies. (fda69abc)

* Added new functions FCLoopFindScalelessTopologies and FCLoopFindOverdeterminedTopologies for analyzing lists of topologies. (7f1166ab)
* Added new function FourSeries for doing Taylor expansions in a 4-momentum. (bc2a81d3)
* Add new function FCLoopAddAuxiliaryMass for implementing Chetyrkin's infrared rearrangement. (bb7bafc4)
* Added new function FCLoopGetFeynAmpDenominators for extracting propagator denominators for expressions. (37c3fa2c)
* Added new function FCLoopRewriteOverdeterminedTopologies that handles expression containing topologies with overdtermined propagator sets. (9ea908d4)
